# 50 — Density maps (`data/densityMap_*.gdm`)

GIANTS `"MDF` binary density maps. They store per-pixel packed-bit values that the terrain `<DetailLayer>` /
`<FoliageMultiLayer>` read (ground state, fill height, crops, weeds…). Generated by `binfmt.blank_gdm`. Reverse-
engineered format (byte-for-byte verified: our blank `densityMap_ground` is exactly 1,048,592 B, the real size).

## Layout
```
Header (16 bytes):
  [0:4]   signature 0x46444D22  ('"MDF', little-endian)
  [4:8]   version u32 = 0
  [8]     mapSizeLog     -> mapPixels = 1 << (v+5)   (9 => 16384)
  [9]     chunkSizeLog   -> chunkPixels = 1 << v      (5 => 32)
  [10]    maxBpp = 2
  [11]    numChannels        (total bit-channels packed per pixel; must match the layer that reads it)
  [12]    numCompressionRanges (how many value-groups the channels split into)
  [13]    numTypeIndexChannels (low channels that are a foliage/crop TYPE index; 0 for plain maps)
  [14],[15] = 0
Then (mapPixels/32)^2 chunks, row-major. Each chunk holds, per compression range, one record:
  [numBitplanes u8][paletteCount u8][palette: paletteCount x u16 LE][numBitplanes x (chunkPixels^2/8) bytes]
Pixel value = palette[index]; index read LSB-first from the bit-planes.
```

## Blank map
Every pixel 0 → each chunk is the empty record `[numBitplanes=0, paletteCount=1, palette[0]=0x0000]` (4 bytes),
repeated once **per compression range**. So a blank `.gdm` = header + `(0,1,0,0) * numRanges` × chunkCount.

## Multi-range densities need the interior split byte(s) — a real crash
The header is 16 bytes for a **single**-range map. For a **multi**-range map, immediately after byte 15 come
`(numCompressionRanges - 1)` bytes giving the INTERIOR channel boundaries, then the chunks begin.
`densityMap_height` is 12 channels in 2 ranges split 0-5 / 6-11 → **byte 16 = 0x06**. Omit it and the engine
reads boundary 0 → `Warning: GDM file has wrong compression channel 0 (0 should be 6)` → **crash**. Verified:
adding the split byte makes our blank height GDM byte-identical in header + exact size (2,097,169 B) to a real one.
`binfmt.blank_gdm(..., range_splits=(6,))` writes it.

## The empty map's densities (headers matched to the terrain layers that read them)
| file | numChannels | ranges | splits | read by |
|------|-------------|--------|--------|---------|
| `densityMap_ground.gdm` | 11 | 1 | — | `terrainDetail` (ground-state decals) |
| `densityMap_height.gdm` | 12 | 2 | `(6,)` → byte16=0x06 | `terrainDetailHeight` (fill/heap heights) |

## Generator
```python
binfmt.blank_gdm(path, mapsize=16384, num_channels=11, num_ranges=1, num_type_index_channels=0)
```
We generate the header + empty chunks from scratch — **never** from another map's `.gdm` as a template.
