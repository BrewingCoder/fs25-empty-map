# 20 — `maps/map.xml`

The map configuration, pointed to by `modDesc … map@configFilename`. It names the terrain i3d and wires up the
map's sub-systems. Generated by `tools/gen_configs.py`.

## Structure

```xml
<map width="8192" height="8192" imageFilename="$data/menu/mapOverview/mapUS_overview.dds">
    <filename>maps/empty16x.i3d</filename>                                   <!-- THE terrain i3d -->
    <sounds       filename="$data/maps/mapUS/sounds/sounds.xml" />
    <environment  filename="$data/maps/mapUS/config/environment.xml" />
    <weed         filename="$data/maps/mapUS/config/weed.xml" />
    <fieldGround  filename="$data/maps/mapUS/config/fieldGround.xml" />
    <farmlands    filename="maps/farmlands.xml" />
    <aiSystem     filename="$data/maps/mapUS/config/aiSystem.xml" />
    <npcs         filename="$data/maps/maps_npcs.xml" />
    <missions     vehicleFilename="$dataS/missionVehicles.xml" />
</map>
```

## Elements

| element | meaning |
|---------|---------|
| `map@width/@height` | map size in metres (8192 for 16x). |
| `map@imageFilename` | the PDA/overview image (`.dds`); `$data` base one is fine. |
| **`filename`** | **child element** → the terrain `.i3d`, relative to mod root (`maps/empty16x.i3d`). |
| `sounds/environment/weed/fieldGround/aiSystem/npcs` | sub-systems. For an empty map every one is a base-game `$data` default — they carry no map data, they're the engine's ambient/weather/AI/NPC configs. |
| `farmlands` | → `maps/farmlands.xml` (map-local; defines farmland parcels keyed to the `farmlands` info layer). |
| `missions@vehicleFilename` | contract lease vehicles (`$dataS` base). |

## GOTCHA (cost a load — the "nil map" crash)

**`<filename>` is REQUIRED and is a child element.** Omitting it makes the engine load a map named `nil`:
```
Info: Loading map: nil
Error: Running LUA method 'update'. Utils.lua:130: invalid argument #1 to 'lower' (string expected, got nil)
```
It must point at the i3d relative to the **mod root** (`maps/empty16x.i3d`), not the maps dir.

## Notes
- No `<fruitTypes>`/`<fillTypes>` ref → the game uses base-game defaults (fine for an empty map; there are no crops).
- Sub-config filenames: `$data/...` = game data dir, `$dataS/...` = game scripts dir, plain `maps/...` = mod-local.
